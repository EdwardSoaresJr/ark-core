# Scheduling Workspace — baseline capture checklist

**Purpose:** 2–3 minute internal baseline video (not marketing). Compare against this after future scheduling changes.

**When:** After A2 + B Engineering. Record before further scheduling optimization.

## Record

Show, in order:

1. Open `/app/appointments` (Scheduling Workspace)
2. Create appointment by clicking a time slot
3. Drag appointment to another time
4. Resize appointment
5. Attempt a conflict (expect rejection)
6. Switch Day ↔ Week
7. Switch Technicians ↔ Bays lanes
8. Edit/save from appointment detail
9. Glance at Capacity rail (Track B bars)

## Store

Save under `docs/runtime/` or shop-private notebook (gitignored if video is large). Name: `scheduling-workspace-baseline-YYYY-MM-DD`.

If a later change makes this flow worse without Floor Proof evidence, revert or fix before shipping.
