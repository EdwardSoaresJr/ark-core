# Owner rhythm

Owners need daily numbers, not monthly surprise.

## Daily

1. **Morning** — Home attention + Operational Report pulse (Sales Posted, Cash Collected, ARO, ELR, Parts Margin).
2. **During day** — Advisors clear aging approvals and parts backlog on the workboard.
3. **Day Review** (`/app/owner/day-review`) — End-of-day: posted sales / cash reconciliation pulse + tomorrow’s queue pressure + name the first move.

Legacy path `/app/owner/bookend` still resolves to Day Review.

## Digest

`shop-excellence:owner-digest` emails active admins at `owner_digest_time` when enabled. Backup nudge — Day Review remains the authoritative close.

## Weekly

Margin Health amber metrics → one fix. Production efficiency. Cash vs posted on Financial tab. One implementation commitment for next week.

## Quarterly

Refresh **Settings → Owner Targets**. Mark target review complete. Reconcile Sales Posted with bookkeeper revenue.
