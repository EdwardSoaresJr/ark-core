# Daily management KPIs

Prefer these on Operational Report / Day Review surfaces:

| KPI | Meaning |
|-----|---------|
| Gross margin % | Posted GP / posted sales |
| ARO | Average repair order value |
| Effective labor rate | Labor $ ÷ billed hours (posted) |
| Parts margin % | Parts GP / parts sales (known costs) |
| Tech efficiency | Billed vs capacity |
| Car count | ROs opened in range |
| Sales Posted | Revenue when ROs posted (`posted_at`) |
| Cash Collected | Payments/deposits cashiered in range |

Supporting: approval rate, deferred opportunity, unpaid pickups, parts/labor mix, break-even (when monthly fixed costs are set).
