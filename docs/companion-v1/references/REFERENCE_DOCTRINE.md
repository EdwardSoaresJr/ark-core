## Reject vs reference

| Label | Ship in Companion? | Still study? |
|-------|-------------------|--------------|
| **Ship** | Yes - ARK equivalent with shop context | Local screenshot + spec |
| **Reference only** | No - wrong domain (CRM pipeline, tasks, app grid) | Yes - layout, chips, kanban scroll, empty states, FAB |
| **Defer** | Not P0 (Ask AI, marketing modules) | Yes - note pattern for later |


- spacing and scan rhythm  
- interaction patterns (sheet, swipe, in-call grid)  
- empty states and loading posture  
- what feels habit-forming on a phone
