# Milestone 7 — Production Feel

**Not polish.** Not rounded corners and animations for their own sake.

**Production feel** is what makes an advisor choose ARK over OpenPhone every single day.

---

## Mission

Companion should **disappear**.

The advisor should feel like they're simply talking to customers. Every interaction should feel inevitable.

**Rule:** Every screen must earn another hour of use — not merely look nice.

---

## After Milestone 7

Put the app in your pocket for **two weeks**.

- Every annoyance → ticket
- Every hesitation → ticket
- Every extra tap → ticket

Those are the improvements users notice.

Then call **Companion v1 finished** — not because it is feature complete, but because the **mission is complete**.

---

## Pillars

### Motion

No jank.

- Native transitions
- Momentum scrolling
- Pull-to-refresh physics
- Swipe elasticity
- Context-preserving animations
- Instant navigation

### Performance

- Every tap under 100ms where possible
- Every list buttery
- Every thread instant
- Cache aggressively
- Prefetch the next likely conversation

### Notifications (aware)

Not: *New Message*

Instead:

```
John Smith
Brake estimate approved.
```

```
Sarah Jones
Missed your call.
```

```
Water pump arrived.
Customer waiting.
```

The notification itself becomes useful.

### Search

Find by: customer · phone · vehicle · plate · VIN · RO · concern · advisor

Instant. Never blank without guidance.

### Empty states

Never blank. Always tell the advisor something useful.

### Haptics

Tiny. Subtle.

- Answer · hang up · swipe complete · mark handled · send message

### Battery

- Background refresh discipline
- Push efficiency
- No polling abuse when app is inactive

### Offline

- Queue messages · retry uploads
- Keep conversations readable
- Never lose notes

### Accessibility

- Big buttons · readable fonts · dark mode · one-handed use

---

## Foundation complete (M1–M6)

| Layer | Delivers |
| --- | --- |
| Inbox | Who needs attention |
| Thread | What they said |
| Calling | Voice without leaving comms |
| Voicemail / recordings | Recovery without hunting |
| Advisor Brief | What to know before responding |
| Operational Context | What is happening with the work |

Anything after Production Feel is **expansion**, not foundation.

---

## Information hierarchy (protect)

```
Identity → Conversation → Advisor Brief → Operational Context
```

Production feel wraps the hierarchy — it must never compete with it.
