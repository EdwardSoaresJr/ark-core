## Evidence gate

No screenshots or live walkthrough → no interaction conclusions. Stub stays `Awaiting evidence`.

Prefer someone **using** the product over polished marketing pages. Marketing is useful for visual rhythm; operational surfaces hold the craft.

**Priority order for capture:**

1. Advisor working an RO  
2. Workflow board  
3. Estimate editing  
4. Customer communication  
5. Search / navigation  
6. Keyboard interactions  
7. Technician workflow  

After a review closes: update Pattern Library **Evidence count** / **Sources**. Log template friction only in the notebook.
