# The Operation Follows the Operator

**Status:** Product north star v1  
**Not:** Phone-First Shop · Mobile-first · Desktop Lite  
**Architecture:** Frozen — earn muscle memory, not more layers

---

## Product sentence

**The operation follows the operator.**

Not the phone. Not the desktop. The **operation**.

When Edward moves from Front Counter → Bay 3 → parking lot → home after hours, the work stays with him. Same customer. Same RO. Same continuity. No sync. No "get back to my computer."

Every major shop system assumes work happens **at the computer** — even ones with mobile apps.

ARK assumes work happens **where the work is happening**.

That is the differentiator.

---

## A day in the shop

**Front Counter** — Customer walks in. Phone stays in pocket. VVX shows:

```
Sarah Johnson
Appointment 3:00
Waiting to check in
```

Edward walks to the customer.

**Parking lot** — Opens phone. Same continuity. Same RO. Photos. VIN scan. Concern.

**Bay 3** — Landon opens phone. Same continuity. Inspection. Photos. Recommendations.

**Office** — Desktop. Everything already exists. No emailing yourself. No catching up.

The operation followed the people doing the work.

## Stations are places, not computers

| Station (place) | Not |
| --- | --- |
| Front Counter | Extension 101 |
| Bay 3 | A workstation row |
| Parking Lot | — |
| Waiting Area | — |
| Parts | — |
| Office | The "real" ARK |
| Portable Station | A phone SKU |

**Devices are views** into station or operator continuity:

Phone · VVX · Tablet · Desktop · Wallboard · Watch

The device is almost irrelevant. Continuity is not.

See ark-station-doctrine.mdc.

## The "wow" moment

Not: *"I checked in a customer from my phone."* (Expected now.)

The moment:

Edward starts an RO at the counter. Walks outside. Takes photos. Walks into Bay 2. Assigns Landon. Walks back inside. Answers Sarah's text.

He never wonders:

- *"Did that save?"*
- *"Which screen was I on?"*
- *"I need to get back to my computer."*

That is **the operation follows the operator**.

## Bottleneck shift

**Architecture is no longer the bottleneck.**

Observations, continuity, workspaces, station orientation, push transport — the grammar exists.

The bottleneck is **muscle memory**.

Next month: Can Edward spend a week using ARK Staff as the floor? Can Molly? Can Landon?

When they stop thinking about devices, ARK crosses from good shop software into something fundamentally different.

## Primary engineering artifact: operation videos

**Stop filming certifications. Film operations.**

| Certification video | Operation video |
| --- | --- |
| "Did we pass?" | "How does Edward actually work?" |

Catalog: [docs/operations/README.md](../operations/README.md)

Recordings of **Demo Auto Repair actually running** — not demos. Reference implementations for this shop; other shops record their own when ARK multi-tenants.

**Engineer sentence (every PR):**

> If you can't point to a real operation this change improves, you probably aren't improving ARK.

**PR acceptance — re-record the operation:**

Fewer interruptions · fewer searches · fewer forgotten steps · fewer context switches → product improved.
