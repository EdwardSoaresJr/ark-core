# ARK Core

Public Core runs the shop. Private SaaS sells the extras. Private Landlord runs the infrastructure.

The policy is [docs/PRODUCT_BOUNDARY.md](docs/PRODUCT_BOUNDARY.md). Do not copy it into another instruction file.

A change belongs here when a shop needs it to operate with no ARK SaaS account. If that is unclear, stop and ask the project owner. Do not add Twilio, voice, Square, PartsTech, provider credential stores, or the legacy Platform texting client.
