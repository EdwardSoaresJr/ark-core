# v0.1 Proof — Capability Invoke

**Scope:** Core capability registry + one end-to-end Workbench button.

## Registry

```
GET /api/v1/core/capabilities
```

Returns generic verbs and registered capability domains (`filesystem`, `git`, `shell`, …).

## End-to-end path (Open Cursor)

```
Workbench button
    → POST /api/v1/core/capabilities/shell/invoke
    → { "action": "open_application", "application": "cursor", "path": "{repo}" }
    → Forge Core spawns cursor (generic verb, not open_cursor)
```

Workbench maps user intent. Core executes generic verb.

## Not in v0.1

- Other workspace buttons (disabled in UI)
- AI, MCP, product-specific commands
- `open_ark_voice`, `test_provisioning`, `review_pr1`
